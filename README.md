# Ising Reproducibility

This repository contains the code, processed data, and documentation needed to reproduce the Ising multihistogram analysis.

## Repository structure

- `scripts/`: scripts to run the analysis and generate figures
- `src/`: reusable source code
- `data/processed/`: processed data used by the analysis
- `data/figure_csv/`: CSV files corresponding to figures and tables
- `docs/`: additional documentation
- `results/`: generated outputs, ignored by Git
- `data/raw/`: raw data, ignored by Git
